v114 — Persistent Signal Library Store

Date: 2026-06-24

Major additions:

• Added PersistentSignalLibraryStore.swift
• Added local JSON-backed persistent storage in the app’s protected Application Support directory
• Seeded Observatory Cognitive Core library into local storage on first launch
• Updated SignalLibraryRegistry to load and manage persisted libraries
• Updated SignalLibraryDetectionEngine to read enabled libraries from the persistent local store
• Updated CognitiveObservationDetector to use persisted enabled libraries
• Updated SignalLibraryScreen with:
    - library enable/disable control
    - persistent-store inspection
    - export-preview inspection
    - reset-to-defaults control
• Added persistent-store provenance tag:
    - store:persistent-local

Architecture note:

Signal libraries are now persisted locally on-device. Compiled defaults remain only as first-launch seed and recovery data. Runtime detection reads the persisted enabled libraries.

Not yet included:

• File-picker import/export workflow
• Library authoring/editing UI
• Third-party library validation, signatures, moderation, licensing, or conflict handling
• Cloud sync or remote database
• Full migration of every detector to library-backed rules
• Biometrics, speaker identity, clinical data, or diagnostic logic
